## 背景
リポジトリ visualizing-jp/data-color-scheme-guide は、初学者向けの日本語スクロール型解説ページ「データの性質に合ったカラースキームの選び方」です。「色相は種類の違いを、明度は量の大小を伝える」という一本の筋で、色が見えるしくみ → 色の3つのつまみ → データの性質とカラースキーム（定性的・連続的・分岐的）→ 色覚の多様性への配慮 → まとめ、の順に説明します。読者は、色彩やデータ可視化を学び始めたばかりの学生・社会人で、スマホで読む人も多いです。

ビルド工程のない静的サイト（バニラJSのESモジュール、D3 v7 同梱）です。骨組み、共有モジュール、9つの図、本文がそろい、いまチェックアウトされている `w3/base` に全部が統合されています。この状態を、3人の査読担当（コード全体のレビュー、科学的な正確さの査読、初学者としての通読）が確認しました。あなたの仕事は、その指摘のうち、下に挙げたものを直すことです。同時に、ほかの3人の担当が、別のファイルを直しています。

最初に `README.md` を読んでください（図の契約、共通の操作部品、撮影と表示検査 `npm run shots`）。作業ブランチは `w3/i1-integration`（`w3/base` から分岐）です。

### B. 本文の修正（`index.html`）
文体と用語は、いまの本文に合わせます（です・ます体、1文60字程度まで、専門用語は初出で言い換える、数字と単位は半角で間を空けない）。

**第0章**
- 導入図の問いは「割合がいちばん高い県と、いちばん低い県」です。本文の問いかけをこれに合わせます。

**第1章**
- 章の最初に、この章の位置づけを1文で置きます：色の使い方を考える土台として、まず目のしくみを見る、という趣旨。
- 「波長スライダーを左から右へ動かして」を、「波長スライダーを左へ動かして」に（初期位置は 580nm で、S の棒が伸びるのは左側です）。
- 感度が最大になる波長を、図の表示と同じ「Sは445nm付近、Mは545nm付近、Lは570nm付近」に。
- 「だからディスプレイは、赤・緑・青（RGB）の3色の光の強さの組み合わせで、ほとんどの色を作れます。」は、理由のつながりが飛んでいて、言い過ぎでもあります。次の趣旨に書き換えます：3つの反応量を別々に変えるには、3種類の光があれば足りる。だからディスプレイは、赤・緑・青（RGB）の3色の光の強さを変えて、多くの色を作っている。ただし、作れる色の範囲（色域）には限りがあり、たとえば580nmの黄色の単色光そのものは、画面では近い色でしか表せない。
- 章の結びの太字の一文も、「…画面は赤・緑・青の3色の光で、多くの色を作れます。」に。
- 「視野2°で測った錐体の感度」を「2°視野の錐体分光感度（視野の中心の狭い範囲での、錐体の感度）」に。

**第2章**
- HSB と OKLCH の段落は、図の中に同じ内容の補足の枠があるので、2文に縮めます（HSB の「明るさ（B）」は明度とは別物であること、このページの図は見た目の明るさに近い OKLCH で計算していること。リンクは残す）。
- マンセルの説明の「すべての色を並べたもの」を「物体の表面の色を並べたもの」に。
- 「色相環」の説明に、図では色相を帯の形に並べていることを一言添えます。

**第3章**
- 定性的スキームの説明「明度は大きく変えません」を、「明度に一方向の順序をつけません」に。
- 「スキーム解剖」のあとの文章の「定性的スキームはおおむね平らで、順序を感じさせません。」を、実測と図の表示に合わせて書き換えます：定性的スキームの明度は上がったり下がったりで、一方向には並ばない。だから順序を感じさせない。
- 定性的データの例を「性別、地方区分、業種」に。続けて、色相だけで区別できる数には限りがあること（8色程度まで。47都道府県を色だけで区別することはできない）を1文で添えます。
- 分岐的データの例に「前年との差、平均との差」を加えます（理解度クイズに、平均との差を問う問題があります）。
- 人口増減率の段落：期間を「2023年10月〜2024年9月の1年間」に。埼玉県（+0.01%）はほぼゼロなので中央の淡い色になること、青の側の色になるのは東京都だけであることを、読者が図と見比べてわかるように書きます。
- 章の結び「ここまでで、「…」と言えるようになりました。」を、第0〜2章と同じ形（その内容を太字の一文で言い切る）にそろえます。第4章・第5章も同じようにそろえます。

**第4章**
- 「色の見え方が多数派と異なる人たちは、スライドでは「色弱・色盲」と呼ばれてきました。」を、「色の見え方が多数派と異なることは、これまで「色弱・色盲」と呼ばれてきました。」に（読者は講義スライドを知りません）。スキーム別の結論のところの「（講義スライドより）」は外します。
- 割合の文のあとに、1文を加えます：そのほとんどはP型とD型で、T型はまれです。（タイプ別の数値は書きません。）
- 見分けにくい色の組の段落を、型ごとに書き分けます：「赤と緑」「オレンジと緑」は主にP型・D型で、「黄色とピンク」「青と緑」は主にT型で、色の差が小さくなる。図の案内は、「色の組」と「見え方」を切り替えて、どの見え方で差が小さくなるかを確かめ、「明度の差」スライダーで差を広げる、という手順にします（図のスライダーのラベルは「明度の差」です）。
- シミュレーションの説明に、限界を1文で加えます：T型の再現は、もとの方法（Machado ほか 2009）が想定していない部分を含むため、特に粗い近似です。
- 「色覚シミュレータ」の案内に、スマホでの読み方を一言添えます（地図は図の上のほうにあります、など。図の構成は別の担当が、地図を操作部品のすぐ下に移します）。

**第5章**
- 「色覚シミュレータ」に触れる箇所を、第4章の図へのページ内リンクにします（A-2）。

**出典の章**
