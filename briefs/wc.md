## 背景
リポジトリ visualizing-jp/data-color-scheme-guide は、初学者向けの日本語スクロール型解説ページ「データの性質に合ったカラースキームの選び方」です。講義スライド「データの性質を表現する色の考え方」をもとに、「色相は種類の違いを、明るさ（明度）は量の大小を伝える」という一本の筋で、色が見えるしくみ → 色の3つのつまみ → データの性質とカラースキーム（定性的・連続的・分岐的）→ 色覚の多様性への配慮 → まとめ、の順に説明します。読者は、色彩やデータ可視化を学び始めたばかりの学生・社会人です。

ビルド工程のない静的サイト（バニラJSのESモジュール、D3 v7 を同梱）で、図を担当ごとに、互いのファイルに触れずに並行して作っています。最初に `README.md` を読んでください。図の契約、担当範囲、共通の操作部品、動かし方、撮影と表示検査（`npm run shots`）が書いてあります。図に渡される `deps`（`d3`、`color`、`palettes`、`prefectures`、`tilemap`）の各関数の意味は、`lib/color.js`・`lib/palettes.js`・`lib/tilemap.js` の JSDoc と、`data/prefectures.json` の `meta` を読んでください。これらは実装済みです。図のひな形は `widgets/_template/`、実装済みの図の例は `widgets/quiz/` です。

あなたの作業ブランチは `w2/wc-scheme-matrix`（`w2/base` から分岐）です。

## 用語と表記（ページ全体で統一）
- スキーム名は「定性的」「連続的」「分岐的」。この順で並べます。
- 見た目の明るさは「明度」（OKLab の L。図の表示では 0〜100%）。鮮やかさは「彩度」。色の種類は「色相」。
- 色覚のタイプは「通常」「P型」「D型」「T型」（操作部品のラベル）。
- 文体は、です・ます体。数字と単位は半角で、間を空けません（39.5%、580nm）。
- 図の中の文言は日本語だけにします（略語とパレット名を除く）。

## 仕事
第3章「データの性質とカラースキーム」の図 `widgets/scheme-matrix/` を作ります。このページの中核の図です。47都道府県のタイル地図を、データ3種 × スキーム3種の9通りで塗り分け、合う組み合わせと、合わない組み合わせで何が起きるかを、読者が自分の目で確かめます。

### データとスキーム
- データ（`deps.prefectures`）：`region`＝地方区分（8区分、定性的データ）／`aged65`＝65歳以上人口の割合（%、連続的データ）／`popChange`＝人口増減率（%、ゼロが基準点、分岐的データ）。
- スキームとパレット：定性的＝`palettes.DEFAULTS.qualitative`、連続的＝`palettes.DEFAULTS.sequential`、分岐的＝`palettes.DEFAULTS.diverging`。
- 塗り方（9通り）：
  - `region` × 定性的：`palettes.get(id, 8)` を、`prefectures.regions` の順に割り当てる。
  - `region` × 連続的・分岐的：`palettes.get(id, 8)` を、`prefectures.regions` の順（北から南）に割り当てる。
  - `aged65` × 連続的：`palettes.scale(id, 5, [最小値, 最大値])`。値が大きいほど濃い色。
  - `aged65` × 分岐的：`palettes.scale(id, 7, [最小値, 最大値], { center: 最小値と最大値の中間 })`。
  - `aged65` × 定性的：`palettes.scale(id, 5, [最小値, 最大値])`（階級の順に、定性的パレットの色が割り当てられる）。
  - `popChange` × 分岐的：`palettes.scale(id, 7, [最小値, 最大値], { center: 0 })`。減少が赤の側、増加が青の側、ゼロ付近が中央の淡い色。
  - `popChange` × 連続的：`palettes.scale(id, 5, [最小値, 最大値])`。
  - `popChange` × 定性的：`palettes.scale(id, 5, [最小値, 最大値])`。

### 図の構成
- 見出し「データとスキームの組み合わせを試す」。
- 操作部品：「データ」の選択（地方区分／65歳以上人口の割合／人口増減率）、「スキーム」の選択（定性的／連続的／分岐的）。初期状態は、地方区分 × 定性的。
- 9通りの一覧（3×3の小さな表）：行がデータ、列がスキーム。各マスに判定の記号と語（○ 合う／△ 条件つき／× 誤読を招く）を出し、いま選んでいる組み合わせを枠で示します。マスを押しても、その組み合わせに切り替わります。
- タイル地図（`deps.tilemap.render`、`labels: 'auto'`）。マスに触れる（ホバー、またはタップ、またはキーボードのフォーカス）と、県名と値（地方名、または「39.5%」「-1.87%」）を地図の下に表示します。
- 凡例：`region` のときは地方名と色。数値のときは階級の境界値と色（境界値は小数1桁または2桁、単位つき）。分岐的スキームで `popChange` のときは、中央の階級に「ゼロ付近」と添えます。
- 判定と理由：下の `verdicts.json` の、いまの組み合わせの `verdict`・`title`・`reason` を、`.verdict` と文で表示します（`aria-live="polite"`）。
- 図の下の注（`.fig-note`）：「データ：総務省統計局『人口推計（2024年10月1日現在）』。人口増減率は2023年10月から2024年10月までの1年間。地方区分は一般的な八地方区分。」

### 確かめる動作
- 9通りすべてで、地図・凡例・判定・理由が切り替わる。判定は、合う（○）が3つ、条件つき（△）が2つ、誤読を招く（×）が4つ。
- `popChange` × 分岐的で、東京都と埼玉県のうち青の側の色になるのは東京都だけ（埼玉県は +0.01% でゼロ付近の中央の階級）、秋田県が最も濃い赤、という塗りになっている。理由文の「増えた東京・埼玉」と塗りが食い違って見える点（埼玉県が中央の色）を、凡例の「ゼロ付近」の表示で読者が理解できるようになっている。
- `aged65` × 連続的で、秋田県が最も濃い色、東京都が最も淡い色。
- マスに触れると県名と値が出る。キーボードだけで、データとスキームの切り替え、9通りの一覧の操作ができる。
- 幅390pxで、3×3の一覧と凡例が崩れない。

## 表示の決まり
README の「図の契約」に従います。特に：SVG には `viewBox` を付ける。幅390pxでも図の中の文字が 11px 以上で表示される。操作部品は `css/base.css` の共通クラスを使い、キーボードで操作できる。ページのUIは無彩色に保ち、色が出るのは図の中の色見本・地図・グラフだけにする。判定（`.verdict`）は記号だけに頼らず、判定の語を文字として含める。操作の結果を文で伝える箇所は `aria-live="polite"` にする。
