## 背景
リポジトリ visualizing-jp/data-color-scheme-guide は、初学者向けの日本語スクロール型解説ページ「データの性質に合ったカラースキームの選び方」です。講義スライド「データの性質を表現する色の考え方」をもとに、「色相は種類の違いを、明るさ（明度）は量の大小を伝える」という一本の筋で、色が見えるしくみ → 色の3つのつまみ → データの性質とカラースキーム（定性的・連続的・分岐的）→ 色覚の多様性への配慮 → まとめ、の順に説明します。読者は、色彩やデータ可視化を学び始めたばかりの学生・社会人です。

ビルド工程のない静的サイト（バニラJSのESモジュール、D3 v7 を同梱）で、図を担当ごとに、互いのファイルに触れずに並行して作っています。最初に `README.md` を読んでください。図の契約、担当範囲、共通の操作部品、動かし方、撮影と表示検査（`npm run shots`）が書いてあります。図に渡される `deps`（`d3`、`color`、`palettes`、`prefectures`、`tilemap`）の各関数の意味は、`lib/color.js`・`lib/palettes.js`・`lib/tilemap.js` の JSDoc と、`data/prefectures.json` の `meta` を読んでください。これらは実装済みです。図のひな形は `widgets/_template/`、実装済みの図の例は `widgets/quiz/` です。

あなたの作業ブランチは `w2/we-cvd-simulator`（`w2/base` から分岐）です。

## 仕事
第4章「色覚の多様性への配慮」の図 `widgets/cvd-simulator/` を作ります。色の見え方は人によって違うこと、そして3種類のカラースキームがその違いにどれだけ強いかを、読者がシミュレーションを切り替えながら確かめる図です。講義スライドの結論は「定性的＝取り扱い注意／連続的＝明るさで色を分けているので、このままでOK／分岐的＝2つの色相が見分けにくい組み合わせでなければOK」で、この図はそれを目で確かめられるようにします。

シミュレーションは `color.simulateCvd(hex, type, severity)` を使います（`type` は `'protan'`＝P型、`'deutan'`＝D型、`'tritan'`＝T型。`severity` は 0〜1）。

### 図の構成
- 見出し「見え方のちがいをシミュレーションする」。
- 操作部品：「見え方」の選択（通常／P型／D型／T型。初期値は通常）、「強さ」スライダー（0〜100%、10%刻み、初期値100%。通常のときは操作できない状態にする）、「定性的パレット」の選択（`palettes.DEFAULTS.qualitative` の `label`／`palettes.DEFAULTS.qualitativeSafe` の `label`）。
- 3つの区画を縦に並べます。各区画は、上段に「もとの色」、下段に「シミュレーション後の色」を、位置をそろえて表示します（見え方が「通常」のときは、下段は上段と同じ色になります）。
  1. 色相環：OKLCH で明度 70%、彩度 0.12 の色を、色相 15° ずつ24色（`color.oklchToHex`）。帯状に並べてかまいません。
  2. 3種類のスキーム：定性的（選んでいる定性的パレットの8色）、連続的（`DEFAULTS.sequential` の7色）、分岐的（`DEFAULTS.diverging` の7色）。それぞれの帯の横に、シミュレーション後に「見分けにくい組」がいくつあるかを表示します。見分けにくい組とは、その帯の中の異なる2色のうち、シミュレーション後の `color.deltaE` が 0.06 未満の組です。0組なら「見分けにくい組はありません」、あれば「見分けにくい組：3組」と表示し、該当する2色の小さな色見本の組を並べます。連続的と分岐的は、隣り合う色どうしではなく、すべての2色の組で数えます。
  3. タイル地図：地方区分（8区分）を、選んでいる定性的パレットで塗った地図（`deps.tilemap.render`、`labels: 'auto'`）。左に「もとの色」、右に「シミュレーション後の色」（幅390pxでは縦に並べる）。
- まとめの文（`aria-live="polite"`）：いまの設定での3種類のスキームの「見分けにくい組」の数を、文で伝えます（例：「D型・強さ100%では、定性的パレット Set2 に見分けにくい組が4組あります。連続的と分岐的には、見分けにくい組はありません。」）。
- 図の下の注（`.fig-note`）：「シミュレーションは Machado ほか（2009）の方法による目安です。実際の見え方には個人差があります。『見分けにくい組』は、シミュレーション後の色の差（OKLab 上の距離）が 0.06 未満の組です。」

### 確かめる動作
- 見え方と強さを切り替えると、3つの区画の下段（と右の地図）が変わる。通常では上段と同じ色。
- P型・D型・T型それぞれ、強さ100%での、定性的（2つのパレットそれぞれ）・連続的・分岐的の「見分けにくい組」の数を表にして報告に書く。連続的は、どの型でも0組であること。
- 定性的パレットを切り替えると、帯と地図が変わり、見分けにくい組の数が変わる。
- 白・黒・グレーはシミュレーションで変わらない（`color.simulateCvd('#808080', …)` が `#808080`）。
- キーボードだけで操作できる。幅390pxで、上段と下段の色の位置がそろっている。

## 表示の決まり
README の「図の契約」に従います。特に：SVG には `viewBox` を付ける。幅390pxでも図の中の文字が 11px 以上で表示される。操作部品は `css/base.css` の共通クラスを使い、キーボードで操作できる。ページのUIは無彩色に保ち、色が出るのは図の中の色見本・地図・グラフだけにする。判定（`.verdict`）は記号だけに頼らず、判定の語を文字として含める。操作の結果を文で伝える箇所は `aria-live="polite"` にする。
