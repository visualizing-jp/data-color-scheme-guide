## 背景
リポジトリ visualizing-jp/data-color-scheme-guide は、初学者向けの日本語スクロール型解説ページ「データの性質に合ったカラースキームの選び方」です。講義スライド「データの性質を表現する色の考え方」をもとに、「色相は種類の違いを、明るさ（明度）は量の大小を伝える」という一本の筋で、色が見えるしくみ → 色の3つのつまみ → データの性質とカラースキーム（定性的・連続的・分岐的）→ 色覚の多様性への配慮 → まとめ、の順に説明します。読者は、色彩やデータ可視化を学び始めたばかりの学生・社会人です。

ビルド工程のない静的サイト（バニラJSのESモジュール、D3 v7 を同梱）で、図・共有モジュール・本文を、担当ごとに互いのファイルに触れずに並行して作っています。最初に `README.md` を読んでください。図の契約、担当範囲、共通の操作部品、動かし方が書いてあります。

あなたの作業ブランチは `w1/wi-decision-flow`（`s0/skeleton` から分岐）です。

## 仕事
第5章「まとめ：自分で選ぶ」の図 `widgets/decision-flow/` を作ります。`widgets/_template/` をひな形にしてください。2つの問いに答えると、3種類のカラースキームのどれを使えばよいかがわかる、判断の手順の図です。ページ全体の結論を1枚にまとめる役割を持ちます。

### 内容
- 見出し「データを見て、スキームを選ぶ」
- 出発点「データを色で表したい」
- 問い1「データに順序はありますか？」
  - いいえ → **定性的スキーム**：色相の違いで区別します。例：性別、都道府県名。色覚への配慮：取り扱い注意（色だけに頼らず、ラベルや形も使う）
  - はい → 問い2へ
- 問い2「ゼロなどの基準点を境に、増加と減少がありますか？」
  - いいえ → **連続的スキーム**：明度を一方向に変えます。例：5段階評価、65歳以上人口の割合。色覚への配慮：明るさで分けているので、このままでOK
  - はい → **分岐的スキーム**：2つの色相を両端に置き、基準点を中央の淡い色にします。例：人口の増減率、前年との差。色覚への配慮：2つの色相が、見分けにくい組み合わせ（赤と緑など）でなければOK

### 図の構成
- 手順全体を、常に見える1枚の図として描きます（問い2つと結論3つを線でつないだ図）。幅の広い画面では横に広がる木の形、幅390pxでは縦に並ぶ形にします。図の中の文字は、HTMLの要素として組みます（SVGは線を描くためだけに使うか、使いません）。こうすると、文字サイズが画面幅で縮みません。
- 各結論には、そのスキームを表す色見本の帯を添えます（色は図の中のデータとして `index.js` に直接書きます。定性的 `#66c2a5 #fc8d62 #8da0cb #e78ac3 #a6d854`、連続的 `#eff3ff #bdd7e7 #6baed6 #3182bd #08519c`、分岐的 `#ca0020 #f4a582 #f7f7f7 #92c5de #0571b0`）。
- 操作：問い1・問い2それぞれに「はい」「いいえ」の選択ボタン（`.ctl-segment`）があり、選ぶと、たどった道筋と行き着いた結論が強調され（線と枠を太くする。色ではなく太さと濃さで示す）、たどらなかった部分は薄くなります。問い1で「いいえ」を選んだときは、問い2は操作できない状態になります。「最初から」ボタンで、何も選んでいない状態（全体が同じ濃さで見える）に戻ります。
- 行き着いた結論は、図の下の `aria-live="polite"` の領域にも文で出します（例：「順序があり、基準点もあるデータです。分岐的スキームが合います。」）。
- 図の下の注（`.fig-note`）：「選んだあとは、グレースケールと色覚シミュレーションで見え方を確かめましょう。」

### 表示の決まり
README の「図の契約」に従います。特に、操作部品は `css/base.css` の共通クラスを使うこと、ページのUIは無彩色に保つこと（色が出るのは色見本の帯だけ）、キーボードで操作できること、動きの演出は `prefers-reduced-motion: reduce` のときは行わないこと。
