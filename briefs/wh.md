## 背景
リポジトリ visualizing-jp/data-color-scheme-guide は、初学者向けの日本語スクロール型解説ページ「データの性質に合ったカラースキームの選び方」です。講義スライド「データの性質を表現する色の考え方」をもとに、「色相は種類の違いを、明るさ（明度）は量の大小を伝える」という一本の筋で、色が見えるしくみ → 色の3つのつまみ → データの性質とカラースキーム（定性的・連続的・分岐的）→ 色覚の多様性への配慮 → まとめ、の順に説明します。読者は、色彩やデータ可視化を学び始めたばかりの学生・社会人です。

ビルド工程のない静的サイト（バニラJSのESモジュール、D3 v7 を同梱）で、図を担当ごとに、互いのファイルに触れずに並行して作っています。最初に `README.md` を読んでください。図の契約、担当範囲、共通の操作部品、動かし方、撮影と表示検査（`npm run shots`）が書いてあります。図に渡される `deps`（`d3`、`color`、`palettes`、`prefectures`、`tilemap`）の各関数の意味は、`lib/color.js`・`lib/palettes.js`・`lib/tilemap.js` の JSDoc と、`data/prefectures.json` の `meta` を読んでください。これらは実装済みです。図のひな形は `widgets/_template/`、実装済みの図の例は `widgets/quiz/` です。

あなたの作業ブランチは `w2/wh-intro-compare`（`w2/base` から分岐）です。

## 用語と表記（ページ全体で統一）
- スキーム名は「定性的」「連続的」「分岐的」。この順で並べます。
- 見た目の明るさは「明度」（OKLab の L。図の表示では 0〜100%）。鮮やかさは「彩度」。色の種類は「色相」。
- 色覚のタイプは「通常」「P型」「D型」「T型」（操作部品のラベル）。
- 文体は、です・ます体。数字と単位は半角で、間を空けません（39.5%、580nm）。
- 図の中の文言は日本語だけにします（略語とパレット名を除く）。

## 仕事
第0章「はじめに」の図 `widgets/intro-compare/` を作ります。ページの最初に置かれ、読者に「同じデータでも、色の付け方しだいで、読み取れることが変わる」と実感させる図です。まだ用語を何も学んでいない読者が触るので、操作は1つだけにします。

### 図の構成
- 見出し「同じデータなのに、見え方がちがう」と、リード文「左右は、65歳以上人口の割合の同じデータです。違うのは、色の付け方だけです。」
- 2枚のタイル地図を横に並べます（幅390pxでは縦に並べる）。どちらも `deps.prefectures` の `aged65`（65歳以上人口の割合、%）を5つの階級に分けて塗ります（`palettes.scale(id, 5, [最小値, 最大値])`）。
  - 配色A：`palettes.DEFAULTS.qualitative`（色相がばらばらの色）。
  - 配色B：`palettes.DEFAULTS.sequential`（濃いほど割合が高い）。
  - 地図は `deps.tilemap.render`、`labels: 'auto'`。それぞれの下に、階級の境界値つきの凡例を付けます（配色Aの凡例も、値の小さい階級から順に並べます）。
- 問い「割合がいちばん高い県と、いちばん低い県は、どこでしょう。まず配色Aで探してみてください。」
- ボタン「答えを見る」。押すと、両方の地図で、いちばん高い県といちばん低い県のマスに印を付け（濃いグレーの太い枠。`tilemap` が作ったマスは `data-code` 属性で探せます。枠は、地図のSVGに重ねた要素で描きます）、答えを文で出します（`aria-live="polite"`）：「いちばん高いのは秋田県（39.5%）、いちばん低いのは東京都（22.7%）です。配色Aでは、色の順序がわからないので、凡例を何度も見比べることになります。配色Bでは、濃さの順に高低が読めます。」県名と値は、データから求めて入れます。ボタンは「もう一度」に変わり、押すと印と答えが消えます。
- マスに触れる（ホバー、タップ、キーボードのフォーカス）と、県名と値を地図の下に表示します。
- 図の下の注（`.fig-note`）：「データ：総務省統計局『人口推計（2024年10月1日現在）』の65歳以上人口の割合。」

### 確かめる動作
- 2枚の地図が同じ階級の区切りで塗られている（同じ県は、両方の地図で同じ階級）。
- 「答えを見る」で、秋田県と東京都のマスに印が付き、答えの文が出る。「もう一度」で消える。
- キーボードだけで操作できる。幅390pxで、地図が縦に並び、凡例が崩れない。

## 表示の決まり
README の「図の契約」に従います。特に：SVG には `viewBox` を付ける。幅390pxでも図の中の文字が 11px 以上で表示される。操作部品は `css/base.css` の共通クラスを使い、キーボードで操作できる。ページのUIは無彩色に保ち、色が出るのは図の中の色見本・地図・グラフだけにする。判定（`.verdict`）は記号だけに頼らず、判定の語を文字として含める。操作の結果を文で伝える箇所は `aria-live="polite"` にする。
