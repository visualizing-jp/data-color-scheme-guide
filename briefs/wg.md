## 背景
リポジトリ visualizing-jp/data-color-scheme-guide は、初学者向けの日本語スクロール型解説ページ「データの性質に合ったカラースキームの選び方」です。講義スライド「データの性質を表現する色の考え方」をもとに、「色相は種類の違いを、明るさ（明度）は量の大小を伝える」という一本の筋で、色が見えるしくみ → 色の3つのつまみ → データの性質とカラースキーム（定性的・連続的・分岐的）→ 色覚の多様性への配慮 → まとめ、の順に説明します。読者は、色彩やデータ可視化を学び始めたばかりの学生・社会人です。

ビルド工程のない静的サイト（バニラJSのESモジュール、D3 v7 を同梱）で、図・共有モジュール・本文を、担当ごとに互いのファイルに触れずに並行して作っています。最初に `README.md` を読んでください。図の契約、担当範囲、共通の操作部品、動かし方が書いてあります。

あなたの作業ブランチは `w1/wg-quiz`（`s0/skeleton` から分岐）です。

## 仕事
第5章「まとめ：自分で選ぶ」の図 `widgets/quiz/` を作ります。`widgets/_template/` をひな形にしてください。データの説明文を読んで、合うカラースキームを3択（定性的／連続的／分岐的）から選ぶ5問のクイズです。ページを読み終えた読者が、「データに順序はあるか」「基準点はあるか」を自分で見極められるかを確かめます。

### 図の構成
- 見出し「理解度クイズ：このデータに合うスキームは？」と、進み具合の表示「1／5」。
- 1問ずつ表示します。問題文、3つの選択肢のボタン（定性的・連続的・分岐的の順）。各ボタンには、そのスキームを表す小さな色見本の帯を添えます（定性的＝色相の違う5色、連続的＝1つの色相の淡→濃の5色、分岐的＝2つの色相と中央の淡い色の5色。色は図の中のデータとして `index.js` に直接書きます。定性的 `#66c2a5 #fc8d62 #8da0cb #e78ac3 #a6d854`、連続的 `#eff3ff #bdd7e7 #6baed6 #3182bd #08519c`、分岐的 `#ca0020 #f4a582 #f7f7f7 #92c5de #0571b0`）。
- 選ぶとすぐに結果を出します。正解のとき：`.verdict--good` で「合っています」と、`explain` の文。不正解のとき：`.verdict--bad` で「合いません」と、選んだ選択肢の `whyNot` の文、続けて正解のスキーム名と `explain` の文。責める言い方はしません。
- 「次の問題へ」ボタンで進みます。5問終わったら、正解数と一言（5問正解「どのデータにも、合うスキームを選べています。」、3〜4問「あと一歩です。順序と基準点の2つの問いを思い出してください。」、2問以下「第3章の図で、合わない組み合わせの見え方をもう一度確かめてみてください。」）、「もう一度」ボタンを出します。
- キーボードだけで最後まで進めること。結果の文は `aria-live="polite"` の領域に出し、スクリーンリーダーで読み上げられるようにします。選んだあとは、選択肢のボタンを操作できない状態にし、どれを選んだか・どれが正解かを、色に頼らず記号と文字で示します。

### 表示の決まり
README の「図の契約」に従います。特に、操作部品は `css/base.css` の共通クラスを使うこと、ページのUIは無彩色に保つこと（色が出るのは色見本の帯だけ）、幅390pxで横スクロールが出ないこと。

## 完了条件
1. `npm test` がすべて通る。
2. Playwright はこの環境に導入済みです（`require('playwright')` がどのディレクトリからでも使え、`chromium.launch()` はオプション不要。ESモジュールからは `createRequire` で読み込めます）。`npm run serve` でサーバを起動し（ポート4173）、確認が終わったら止めます。 `widgets/quiz/demo.html` を幅1280pxと幅390pxで開き、次を確かめる：コンソールエラー0件、横スクロールなし、全問正解で進めたときに「5問中5問」の結果が出る、各問でわざと別の選択肢を選んだときにその選択肢の `whyNot` の文が出る、Tab と Enter だけで5問を最後まで進められる、「もう一度」で1問目に戻る。
3. `index.html` でも、第5章にこの図が表示される。
