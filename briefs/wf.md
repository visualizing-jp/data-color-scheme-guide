## 背景
リポジトリ visualizing-jp/data-color-scheme-guide は、初学者向けの日本語スクロール型解説ページ「データの性質に合ったカラースキームの選び方」です。講義スライド「データの性質を表現する色の考え方」をもとに、「色相は種類の違いを、明るさ（明度）は量の大小を伝える」という一本の筋で、色が見えるしくみ → 色の3つのつまみ → データの性質とカラースキーム（定性的・連続的・分岐的）→ 色覚の多様性への配慮 → まとめ、の順に説明します。読者は、色彩やデータ可視化を学び始めたばかりの学生・社会人です。

ビルド工程のない静的サイト（バニラJSのESモジュール、D3 v7 を同梱）で、図を担当ごとに、互いのファイルに触れずに並行して作っています。最初に `README.md` を読んでください。図の契約、担当範囲、共通の操作部品、動かし方、撮影と表示検査（`npm run shots`）が書いてあります。図に渡される `deps`（`d3`、`color`、`palettes`、`prefectures`、`tilemap`）の各関数の意味は、`lib/color.js`・`lib/palettes.js`・`lib/tilemap.js` の JSDoc と、`data/prefectures.json` の `meta` を読んでください。これらは実装済みです。図のひな形は `widgets/_template/`、実装済みの図の例は `widgets/quiz/` です。

あなたの作業ブランチは `w2/wf-problem-pairs`（`w2/base` から分岐）です。

## 仕事
第4章「色覚の多様性への配慮」の図 `widgets/problem-pairs/` を作ります。講義スライドは、Datawrapper の記事（https://www.datawrapper.de/blog/colorblind-check/ ）をもとに、「問題のある色は通常、同じような明るさを持つ『赤と緑』『オレンジと緑』『黄色とピンク』『青と緑』の組み合わせ。直し方は、色を暗くするか明るくするかだけ」と教えています。この図では、同じ明度の2色に、読者がスライダーで明度の差をつけ、見分けやすくなる様子を確かめます。

### データファイル
`widgets/problem-pairs/pairs.json` に、下の内容をそのまま置き、mount の中で fetch します（mount は async にします）。4組とも、2色の明度（OKLab の L）がそろえてあります。`note` は使いません（どの型で見分けにくいかは、図が計算して表示します）。

### 図の構成
- 見出し「同じ明るさの2色に、明度の差をつける」。
- 操作部品：「色の組」の選択（赤と緑／オレンジと緑／黄色とピンク／青と緑）、「見え方」の選択（通常／P型／D型／T型。初期値は D型。強さは100%固定）、「明度の差」スライダー（0〜40%、1%刻み、初期値0%）、ボタン「差をなくす」。
- 明度の差のつけ方：もとの2色を `color.hexToOklch` で色相・彩度・明度に分け、差を d とすると、色Aの明度を +d/2、色Bの明度を -d/2 します（色相と彩度はそのまま。`color.oklchToHex` で色に戻します。出せない彩度は自動で下がります）。
- 見え方を並べた3つの表示：「もとの色」「（選んだ型）の見え方」「グレースケール」。それぞれ、2色を隙間なく隣り合わせた大きめの色見本にします（境目が見えるかどうかが、見分けやすさの手がかりになります）。見え方が「通常」のときは、2つめの表示は出しません。
- 数値と判定（`aria-live="polite"`）：選んだ見え方での2色の差（`color.deltaE`、小数2桁）と、判定。差が 0.05 未満「見分けにくい」（`.verdict--bad`）、0.05 以上 0.10 未満「やや見分けにくい」（`.verdict--caution`）、0.10 以上「見分けやすい」（`.verdict--good`）。
- 4つの見え方での差の一覧：通常・P型・D型・T型それぞれでの2色の差を、小さな横棒と数値で並べ、どの型で差が小さくなるかがひと目でわかるようにします（明度の差を動かすと更新されます）。
- 図の下の注（`.fig-note`）：「色の組は Datawrapper の記事によります。シミュレーションは目安で、実際の見え方には個人差があります。差は OKLab 上の距離です。」

### 確かめる動作
- 4組それぞれについて、明度の差 0% のときの、通常・P型・D型・T型での2色の差を表にして報告に書く。あわせて、各型で判定が「見分けやすい」に変わる明度の差（%）を報告に書く。
- 明度の差を大きくすると、どの型でも2色の差が大きくなり、グレースケールの表示でも境目が見えるようになる。
- 「差をなくす」で 0% に戻る。色の組や見え方を切り替えると、表示と数値が変わる。
- キーボードだけで操作できる。幅390pxで、3つの表示が崩れない。

## 表示の決まり
README の「図の契約」に従います。特に：SVG には `viewBox` を付ける。幅390pxでも図の中の文字が 11px 以上で表示される。操作部品は `css/base.css` の共通クラスを使い、キーボードで操作できる。ページのUIは無彩色に保ち、色が出るのは図の中の色見本・地図・グラフだけにする。判定（`.verdict`）は記号だけに頼らず、判定の語を文字として含める。操作の結果を文で伝える箇所は `aria-live="polite"` にする。
